# 自愈、能力规则与战斗平衡定制更新

## 诊断及取舍

| 症状 | 已确认原因 | 改动 |
| --- | --- | --- |
| 快速自愈描述“每小时恢复满”，生命仍 60 | 特质编译器只有学习规则；没有游戏时间被动事件 | 识别时间恢复规则，按成功推进的游戏分钟累计并持久化，不依赖正文声称恢复 |
| 部分能力只在文字里发生 | 描述与执行规则分离，无法识别的设定未明确阻止误保存 | 创建前展示数值合同；未识别自定义特质需补充。游戏“绝艺”面板提供明确绑定和执行记录 |
| 高武力被普通多人敌人拖死 | 伤害只是武力的线性小增量，行动速度不吃武力，普通攻击漏用被动伤害倍率 | 新个人战 V2.2 使用对称武力差距倍率和行动频率，并修复普通攻击倍率；旧检查点保留原公式 |
| 战争质量优势被稀释 | 接敌拥挤错误地对含统帅/训练/质量的有效战力做对数压缩 | 新战争 V2.7 只按人数差计算接敌折减，质量优势完整参与，兵力优势仍有效 |

这是单机叙事游戏的英雄差距方案，不是 PvP 数值平等设计。强者应明显压制弱者；同级、濒死、兵力悬殊和兵种/地形仍形成风险。没有采用玩家专属必胜或隐藏橡皮筋调整。

## 数值模型

- 新个人战命中：`78 + 0.8×武力差 + 0.04×智力差 + 装备/能力修正 + 0.1×机运差`，最终 5%～99%。
- 武力伤害基础项由 `floor(武力×0.16)` 改为 `floor(武力×0.22)`；伤害再乘 `clamp(exp(0.016×武力差), 0.25, 4)`。普通攻击和攻击绝艺使用相同差距倍率，再处理暴击、格挡、护甲及难度。
- 被动伤害倍率合计上限 ×10，普通攻击伤害上限 200；临时敌人保留按原型与武力差修正的上限。标准护甲与格挡规则保留。
- 新战斗行动速度乘 `1 + 0.006×(武力-50)`，最终 50～220。新快照保留最高 160 武力；旧版本仍使用原上限和原始公式。
- 新战争有效战力仍包含训练、士气、质量、战备、补给、疲劳、统帅、地形、兵种和战术。仅人数较多的一方乘接敌比例 `(敌兵数 + 人数差×clamp(0.65+0.002×协同,0.65,0.85))/我兵数`，不再压缩质量优势。
- 明确绑定的战争战力加成不受普通特质 30% 上限压低，按界面约定执行，合计仍受 280% 总上限约束。

独立手算校验：无装备、无护甲、无暴击格挡、随机浮动 0，100 武力打 40 武力：`round((5+22)×exp(0.96)) = 71`。对应两次命中击倒 100 生命目标，不以平均伤害取整冒充期望击杀次数。

## 实测结果

每种场景和规则版本运行 256 个固定种子 `balance:0`～`balance:255`；直接调用真实引擎及本地 AI，标准难度，无装备/绝艺、同机运，个人战双方智力和统率均为 50。战争同训练与补给，均稳步推进。

| 场景 | 旧规则 | 新规则 |
| --- | --- | --- |
| 满血 100 武力对单个 40 | 玩家行动中位数 5，P90 6 | 中位数 2，P90 3 |
| 满血 100 对三个 40 | 胜率 13.28%，存活生命中位数 0 | 本批 256 场均胜，结束生命中位数 94，行动中位数 8 |
| 60 生命的 100 对三个 40 | 本批 256 场均败 | 本批 256 场均胜，结束生命中位数 54 |
| 满血 100 对 100 | 玩家胜率 53.52% | 玩家胜率 53.13%，仍有同级风险 |
| 仅 10 生命的 100 对 100 | 本批无胜场 | 胜率 0.39%，低生命仍危险 |
| 同为千人，统率/智力 100 对 40 | 己方伤亡中位数 49，对方 183 | 己方 27，对方 213 |
| 统帅 100，以 500 对 5000 | 本批未胜 | 本批未胜；不会无视十倍兵力 |

胜率是这批可重现样本的频率，不是所有配置下的必胜/必败保证；并非真人游玩遥测。战争同级对称场景在十轮内均为平局，不应把“玩家胜率 0”误解为全败。兵种、地形、装备与原有绝艺另由既有校准回归覆盖。

## 持久模拟工具

- 输入：`scripts/balance/scenarios.json`（人数、能力、生命与种子数）。
- 引擎/断言：`tests/balance/EncounterBalance.test.ts`。直接运行 `npm run balance:simulate`；PowerShell 增大样本：`$env:BALANCE_SEEDS='256'; npm run balance:simulate`。
- 默认输出：`output/balance/latest.json`。验收结果保留在 `scripts/balance/accepted-2026-09-09.json`，包含旧/新版本、P50/P90、胜率、平局率和伤亡。
- 自动门槛：高武力对三个低武力对手胜率至少 95%；同级胜率在 30%～70%；60 生命强者仍需至少 85%；反向劣势及十倍兵力差不得因为玩家身份而获胜；所有模拟必须有终点。

## 能力与旧档边界

- 周期恢复、每回合恢复、主动使用回满、伤害倍率、命中/格挡/速度、战争战力、学习倍率和完美学习有明确执行合同。复杂条件、任意属性修改、复活及新的世界机制不能仅靠自由文本保证；必须扩展引擎或改用受支持规则。不可宣称已经支持任意自然语言能力。
- 自动识别的旧快速自愈可在读档规范化后继续使用，下一小时按累计游戏时间执行；不在加载时凭空回溯并补发历史治疗。时间未推进、失败未提交、死亡和重复结算不会获得免费治疗。
- 规则绑定会替换该项已保存权威规则；原描述不会被改写。普通判定钩子或已有标准投影不等于“完全无效”，界面将其与已绑定权威规则区分。
- 不改正在进行的已封存战斗快照，避免重算历史战果或破坏哈希；新战斗使用新规则。保存、取消、切档、AVG 图库和写回恢复继续回归。

回退：源代码版本历史可回退；勿修改已封存结果。若同级胜率越出验收范围、技能倍率不生效或旧档读写失败，停止发布并用对应测试复现后修正，不靠进一步加大参数掩盖实现错误。
