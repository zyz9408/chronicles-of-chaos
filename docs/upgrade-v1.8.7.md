# 1.8.7 兼容定制版升级记录

## 来源与边界

2026-09-08/09 核对 [参考网站](https://cocsg.pages.dev/)：最新显示 1.8.7，发布日志日期 2026-09-08，主入口 `index-y3Rn7Pqh.js`，游戏模块 `GameScreen-C_xovK6i.js`。原作者 [公开仓库](https://github.com/RedCliffScribe/chronicles-of-chaos) 最近源码发布为 1.7.24（`e18c041`），没有对应 1.8.7 原始源码或 source map。

本次是对公开行为的兼容实现，不是原始源码合并或逐字还原。以现有可编辑项目为基础，保留此前已验证的定制战斗、玩家权威能力、AVG 生图、同类图库固定绑定及资源包严格匹配，不执行下载的发布脚本。美术包未改动，既有图片不会自动重新生成。

## 对齐内容

| 参考版本/范围 | 本项目实现与验证点 |
| --- | --- |
| 1.8.5 恢复任务生命周期 | 成功新回合结束旧恢复任务；加载迁移清理滞留任务，不抹除原失败回合诊断，不降低同回合完整性检查 |
| 1.8.6 固定人物 | 只凭唯一且性别一致的注册身份链接 NPC；AVG 身份不直接进入世界写回，档案和关系统一映射；冲突不合并，生日不改写 |
| 1.8.7 人物与羁绊 | 补档保留固定身份、父母、后台演化、战斗记录；普通羁绊更新保留已有未建档成员，显式 NPC ID 仍为权威 |
| 1.8.7 视觉身份衔接 | 唯一固定人物晋升为 NPC 时可沿用原本地图片，不重写历史冻结帧；已有 NPC 专属图片优先，歧义和已删除 NPC 不自动链接 |
| 1.8.7 保存安全 | 换装、卸装、删物品、成长点先提交后显示，生成期间拦截修改；常规新回合提交检查来源状态，拒绝覆盖已改变的存档 |
| 1.8.7 资源存储 | OPFS 安全策略拒绝可重读 ZIP、重新校验后存入 IndexedDB；配额错误和资源损坏仍失败，不触碰旧有效包 |
| 1.8.7 API 响应 | 流式请求返回普通 JSON 时在同一响应中解析正文、用量和结束原因，不增加请求；空正文仍失败 |
| 1.8.7 保存读取开销 | 正常提交读取当前存档、摘要和同档快照；仅清理到期存档相关快照键；旧摘要索引在事务内初始化 |
| 1.8.7 云覆盖 | 云存档及云设置提交成功后，清理旧对象失败不会回删新对象；提交前失败清理暂存新对象、保留旧对象 |

## 不包含的能力

- 不提供原站私有后端与凭据，GitHub Pages 不能运行 Cloudflare Functions；云覆盖修复只作为后端源码与模拟事务测试交付。
- 不推测、恢复过去已被拒绝的关系或人物事实，不通过改年龄绕过门禁。
- 不保证不同代码组织、非公开服务和未观察路径与原站内部实现完全相同。

## 回归要求

全量单元测试、类型与 ESLint、生产构建；浏览器覆盖存档隔离/取消、失败提交重试、状态恢复、AVG 生图与加载、直接战斗。专门覆盖固定人物 ID 映射与冲突、图片衔接、OPFS 拒绝和配额失败、JSON 响应、过期覆盖拒绝、云端提交后清理失败。
